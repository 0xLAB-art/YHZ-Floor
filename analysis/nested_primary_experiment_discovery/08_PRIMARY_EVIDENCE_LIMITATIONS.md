# Primary evidence limitations

1. The nested checkout is heavily dirty. Current file content, not a clean committed release, is the audited object.
2. The corrected pass inventories all 465 non-Git working-tree files and parses every JSON, JSONL, and TSV file. It does not claim that every repetitive trace byte was manually interpreted line-by-line; bytecode remains metadata-only.
3. Several headline records are summaries without raw sample files, complete transcripts, or immutable environment identifiers.
4. C2 original and C2-T1 embed outcomes but do not retain the same trace-level evidence as C2b.
5. D1’s 16/16 Spread-Table result lacks the raw timing file and complete source-to-run chain needed for independent reproduction.
6. A1 compares different environments and target builds; the contrast is not a causal environment experiment.
7. B1 retains model responses and summaries, but is not an executable attack campaign and has no independent behavioral oracle.
8. Agent sessions mix model/provider routes and operational failures. Provider-unavailable, no-claim, parser, relay, and oracle outcomes cannot be collapsed into a capability denominator.
9. v2 and v3 result trees are byte-identical copies. They do not provide independent repetition, although their source trees differ.
10. The fixed-operation rerun establishes local operation/verifier behavior, not agent completion, model capability, or agent timing.
11. README and integration reports were used for navigation and coverage comparison, never as sole evidence of an outcome.
12. The full-tree manifest is an inventory artifact, not a scientific result; file presence does not establish physical execution or independence.
13. No external literature comparison or new experiment was used to upgrade any retained result.
14. Git tracking state is heterogeneous: one data result is untracked, 74 v2 session files are ignored, and 74 v3 session files are untracked. All were retained in the filesystem inventory, hashed, and included in the evidence review. This limits provenance and ordinary checkout reproducibility; it does not invalidate the observations or justify omitting them. The identical v2/v3 hashes prevent counting them as independent repetitions.
