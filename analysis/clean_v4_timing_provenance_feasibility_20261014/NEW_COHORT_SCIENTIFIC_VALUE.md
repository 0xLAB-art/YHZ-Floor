# Scientific value of an additional real-agent cohort

EXP-034 supplies capture-first real-agent identity with H1=0/12 because the retained local runtime has no immutable image digest. EXP-035 supplies content-addressed source/config/task/environment/execution/result linkage with H1=3/3, but uses a deterministic local task and no model. These separate results do not establish that a real-agent execution and its task result can be jointly linked under the unchanged H1 criterion.

A content-addressed real-agent session could support the new bounded claim that at least one real hosted-agent run was linked to a frozen local source/configuration/task/runtime/execution/result record under H1. It would not establish provider weight identity, hosted-model reproducibility, broad task capability, performance superiority, or causal effect of provenance controls. External backend mutability remains material.

The joint provenance observation is scientifically distinct from a higher H1 numerator. One or two real sessions can qualify end-to-end wiring and show a concrete joint observation, but cannot estimate success yield. A large cohort is only justified if the paper intends to estimate replicated real-agent outcomes under the content-addressed local runtime; that is not needed to resolve the provenance criterion itself.
