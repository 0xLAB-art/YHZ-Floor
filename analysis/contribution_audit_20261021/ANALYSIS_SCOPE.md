# Decision scope fixed before synthesis

The deliverable is an executed contribution audit, a claim/evidence/closest-prior-work matrix, a defensible central contribution draft, and the smallest remaining validation study if the evidence needs it. Existing negative/invalid records are not repaired. No favorable result is required.

Decision gates:

1. Admission: distinguish actual v3 failures from historical-policy counterfactuals. Count correct programs rejected for unused imports separately from referenced-import restrictions. Program cleanup is a derivative intervention validated only on the fixed fixture, not proof of universal semantic equivalence.
2. Paired effects: quantify policy-dependent representation differences using matched instance units. Preserve original preregistered L3 analysis. New interactions, cleanup sensitivities and subgroup analyses are exploratory; no model-rank or universal equivalence claim follows.
3. Attribution: evaluate common claim contracts. Full-attribution-only validators cannot be treated as inferior general partial-claim validators on an unsupported output scope. Distinguish synthetic composer tests, actual component behavior and operational reachability. Holdout status follows execution history, not directory naming.
4. Prior work: inspect full primary papers and relevant appendices. A measured domain application may be valuable without a new general principle. Absence claims need source coverage and an explicit uncertainty boundary. Do not define novelty by an arbitrarily narrow combination of familiar ingredients.
5. Scientific impact: state what evaluation decision the findings change, under which assumptions, and what would falsify the proposed interpretation. Portability of the local artifact is reproducibility, not independent benchmark validation.

Root will verify worker computations and input preservation before issuing the synthesis. Manuscript sources remain unchanged during this audit so the author’s ongoing edits are preserved; any paper-ready text is a separate proposal grounded in the resulting matrix.
